# 📚 C & C++ Algorithmic Practice

Welcome to my personal playground for **C** and **C++**. This repository documents my progression in low-level programming, focusing on algorithmic logic, data structures, and memory management.

## 📂 Repository Structure

* **`C++/`**: Object-Oriented implementations, templates, and complex logical exercises.
* **`C/`**: Procedural programming, pointer arithmetic, and system-level logic.

---

## 🌟 Featured Exercises

### C++ Projects
* **🛠️ Floating Flooring Simulator:**
  * Simulates the logistics of flooring installation.
  * *Key Concepts:* Arrays, complex loops, and conditional logic for layout management.

* **🔢 Prime Number Validator:**
  * High-performance algorithm to verify prime numbers.
  * *Key Concepts:* Mathematical optimization and algorithmic efficiency.

* **🎲 Random Number Guess Game:**
  * Interactive CLI game with random generation engine.
  * *Key Concepts:* User input handling, loops, and state management.

### C Projects
* **🖨️ ASCII-Printer:** Character handling and loop iteration demonstrations.
* **➗ Arithmetic-Sequence:** Mathematical sequence generation and arithmetic logic.
* **♟️ Bishop-Chess:** Logic regarding chess piece movement limits using 2D arrays.
* **📉 Discount-Calculator:** Practical implementation of percentage logic and input validation.
* **🔢 Fibonacci Series:** Multiple implementations (Iterative vs Recursive) with input validation.
* **📅 Leap-Year Calculator:** Date verification logic using nested conditionals.

## 🚀 How to Use

Each file is a standalone program designed to be compiled individually.

**Clone the repository:**
```bash
git clone https://github.com/Gui2Barbieri/C-Cpp-Learning.git
```
Compile a specific file (Example):
```bash
g++ C++/PrimeNumber.cpp -o prime_check
./prime_check
```
